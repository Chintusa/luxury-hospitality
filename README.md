- **Curated Private Pursuits**: 98-foot Riva superyacht charters, private helicopter archipelago flights, and 300-torch candlelit sandbank stargazing.
- **Accolades & Guest Testimonials**: Condé Nast Gold List, Forbes Double 5-Star awards, and an interactive guest chronicle carousel.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- pnpm (v9 or higher)

### Installation
```bash
# Clone the repository
git clone <REPO_URL>
cd "Luxury hospitality"

# Install dependencies
pnpm install

# Start development server
pnpm run dev
```

The application will be accessible at `http://localhost:19280/`.

### Production Build
```bash
pnpm run build
```
Build output is generated into the `dist/` directory.
